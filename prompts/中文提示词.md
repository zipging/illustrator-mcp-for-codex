# 中文提示词

## 复现参考图

```text
请使用 Illustrator MCP 在 Adobe Illustrator 中复现这张参考图，输出最终可交付的 PNG 预览图。

交付物：
- 从 Illustrator 导出的 `.png` 预览图
- 如果使用脚本生成，请同时保留 `.jsx` 脚本
- 只有用户明确要求时，才额外保存本地 `.ai` 工作文件

要求：
- 尽量用矢量图形重画，不要直接把原始 PNG 嵌进去当最终作品。
- 可以去网上找矢量风格素材替代原始 PNG 中的器官、图标、示意结构，也可以自己简化绘制。
- 保留原图的面板结构、层级、颜色和主要信息。
- 所有文字必须放在固定文本框中，并留出足够边距。
- 文字不能和文字、边框、箭头、图例、图形、面板线发生重叠或错位。
- 箭头位置要清楚，不能穿过文字或重要图形，箭头头部要准确指向目标。
- 长标签和公式如果放不下，要主动换行或简写。
- 最后必须导出 PNG 预览并检查，发现错位、截断、压线、箭头不合理时继续修改。
- 只有达到最终可交付版本后再回复。
```

## 先用 GPT Image 生成参考图，再让 Codex 矢量复现

```text
第一步：请使用 GPT Image / GPT Image 2（如果可用）生成一张高清、干净、适合后续矢量复现的科学图示参考图。

图像要求：
- 白色背景
- 多面板布局清晰
- 标签大而清楚，不要生成过小文字
- 尽量使用示意图、图标、热图、箭头、流程框、图例等矢量感元素
- 所有文字和箭头周围要有足够留白
- 风格接近论文中的机制图或方法图

第二步：把生成的 PNG 发给 Codex，并要求 Codex 使用 Illustrator MCP 复现并导出最终 PNG。只有需要继续编辑时，再要求 Codex 额外保存本地 `.ai` 工作文件。
```
